# Job Tracker Backend

A full-stack MERN Job Tracker backend built using Node.js, Express.js, MongoDB, and JWT Authentication.

## Features

- User Authentication (JWT)
- Add Job Applications
- Update Job Status
- Delete Jobs
- Dashboard Statistics
- MongoDB Atlas Integration
- Secure Environment Variables

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- dotenv

## API Routes

### Auth Routes
- POST /auth/register
- POST /auth/login

### Job Routes
- GET /jobs
- POST /jobs
- PUT /jobs/:id
- DELETE /jobs/:id
- GET /jobs/stats

npm install
npm run dev
